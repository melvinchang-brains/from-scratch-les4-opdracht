# Les 4 -- Flexbox: Rekupe Digital Agency

In deze opdracht ga je een one-pager maken voor een fictieve digital
agency genaamd **Rekupe**.\
Je oefent hiermee **Flexbox** en **responsief design**.

------------------------------------------------------------------------

## 🚀 Opdracht

Bouw de website van **Rekupe Digital Agency** na. Je krijgt een
starter-repository met een `index.html` en assets (afbeeldingen en
iconen). De bedoeling is dat je zelf de styling (`style.css`) maakt.

------------------------------------------------------------------------

## 📑 Eisen

1.  **Layout**
    -   Gebruik **Flexbox** voor de opbouw van de layout.
    -   Maximaal 1200px breed, gecentreerd met `margin: 0 auto;`.
    -   Responsive:
        -   Desktop (≥ 1024px): projecten naast elkaar, services naast
            elkaar.
        -   Tablet (768--1023px): 2 kolommen waar mogelijk.
        -   Mobiel (≤ 767px): alles onder elkaar.
2.  **Secties**
    -   **Header** met logo/naam en navigatie.
    -   **Intro/Hello** sectie met korte tekst ("Rekupe is a digital
        agency in Los Angeles...").
    -   **Projects** sectie met minstens 3 projecten:
        -   Titel, korte tekst, afbeelding.
        -   Op desktop wisselt de afbeelding links/rechts per project.
    -   **Services** sectie met 4 blokken (icons + titel).
    -   **Footer** met een contactlink.
3.  **Typografie & kleuren**
    -   Gebruik een systeemfont of Google Font (bijvoorbeeld *Inter*).
    -   Zachte grijstinten voor achtergrond.
    -   Links en knoppen hebben een **hover-state**.
4.  **Bonus**
    -   Voeg een golfje (SVG of `::after`) toe onder de header.
    -   Kleine animatie (bijvoorbeeld op hover van services of knoppen).

------------------------------------------------------------------------

## 📂 Bestanden

-   `index.html` -- basisstructuur.
-   `style.css` -- jouw styling.
-   `assets/` -- bevat alle afbeeldingen, icons en screenshots.

------------------------------------------------------------------------

## ✅ Criteria

-   Je gebruikt **Flexbox** overal waar het kan (geen CSS Grid).
-   De site is **responsive** en goed bruikbaar op mobiel.
-   Netjes gebruik van semantische HTML (`header`, `section`, `article`,
    `footer`).
-   Consistente code (inspringen, class-namen, enz.).
